layoffs-data-cleaning
Data Cleaning project for table containing data of companies and their layoffs using MYSQL.


📌 Project Overview
This project focuses on cleaning and preparing a layoffs dataset using MySQL.

The goal was to identify and handle common data-quality issues such as duplicate records, inconsistent values, missing data, and incorrect date formats, and then prepare the cleaned data for further analysis.



🛠️ Tools & Technologies
* MySQL
* MySQL Workbench


🧹 Data Cleaning Process
The following data-cleaning tasks were performed:

* Removed duplicate records
* Standardized company names
* Standardized industry values
* Converted date values into the correct `DATE` format
* Identified and handled `NULL` and blank values
* Populated missing industry values using a self `JOIN`
* Removed unnecessary records
* Created a staging table to preserve the original dataset
